# 预备篇 · 基础教程

**使命：把四部前沿内容所需的全部基础概念，用由浅入深的教科书方式讲透——从本科水平走到能读前沿。**

每章都按同一套教学法写：**物理直觉 → 严格定义 → 逐步推导（不跳步）→ 带真实数字的算例**，章末固定有「常见误解」清单和「通往前沿」指路牌（告诉你这一章的知识在四部的哪里被用到、被挑战）。
