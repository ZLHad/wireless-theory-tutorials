# 导览篇 · 领域画像

在读任何一章之前，先看清全局：无线通信这个领域由哪些部分组成，各部分成熟到哪一步，前沿卡在哪里，以及在这个站点里该怎么读。导览篇不推公式，讲的是地图、路径和贯穿全站的几条线索。

| 页 | 读完能得到什么 |
|---|---|
| [领域地图](01-field-map.md) | 跟着一条消息走一遍无线链路；把领域分成五层，每层研究什么、成熟到哪里；近二十个前沿方向各自卡在哪里、往哪里走；期刊、标准与入门读物；本站覆盖了地图的哪一块 |
| [学习路径](02-learning-paths.md) | 三种读法和各自要花的时间；46 章的一句话目录，标出每章先读哪一节、第一遍可以跳过什么；读四部之前最好已经会的十五件事 |
| [开篇之作](03-seminal-papers.md) | 十几篇真正打开一个方向的论文，每篇按同一条思路拆开：它面对的最简案例、抓到的洞见、搭起的模型、给出的第一个干净的解，以及它打开了什么门、今天还剩什么没解决 |
| [时间线与标准](04-timeline-standards.md) | 从香农到 6G 的三条时间线；3GPP 与国际电联怎样制定标准，一项技术要过哪几道关；以 AI/ML 空口走一遍完整流程；一组"从论文到标准走了多少年"的数；截至 2026 年 10 月 6G 已经定下的事 |
| [八条线索](05-eight-threads.md) | 贯穿全站的八个问题：时间尺度、信息结构、自由度与秩、残差与失配、代价、采纳、极限与基线、任务与价值。每个问题既是一条把相关章节串起来的知识线索，也是一种审视方案的方法 |
| [方向的生命周期](06-direction-lifecycle.md) | 一个研究方向从存在、开门、立核、推广、饱和到轮回的六个阶段；十几个方向的论文数曲线；门已经开了的、产业换了提法才进门的、至今没开的；一张截至 2026 年 10 月的前沿雷达表 |

刚入门的读者建议按表中顺序读：先用领域地图看清全貌，再用学习路径选一种读法；开篇之作可以穿插着读，每读完预备篇的一章，就去看那个方向的开篇论文是怎样想出来的；读过几章预备篇之后再回来读八条线索，那时会更有体会；时间线与标准、方向的生命周期适合在读完预备篇第 9–11 章之后读，用来判断一个方向值不值得进去。已经在做研究的读者可以直接读八条线索，再从各条线索的阅读路径进入四部。

导览篇里关于各方向现状与走向的判断是本站的归纳，标【本站判断】；标准与产业进展写明了截至的日期。各章正文用的状态标签，说明见[首页](../index.md#诚实声明与状态标签)。
