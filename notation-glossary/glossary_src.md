# 术语表

收全站核心术语，按"所属部"分五节，每条一句白话解释。所属部指这个概念主要在哪一部讲透，和它第一次露面的位置不一定相同，比如"分层的代价"第一次出现在第二部，讲透在第三部。

几条读法说明：

- **首次出现**：按阅读顺序（预备篇 → 第四部）找第一次在正文里出现的位置；首页、各部导读页、章首"你将学会"列表与参考文献不计。那一处如果只是提了一下名字，标"（点名）"。
- **所属部 · 主讲**：真正定义或讲透这个概念的小节。节内各条按主讲位置排序，所以每一节也可以当作读这一部之前的术语预习单。
- 标【本站提法】的是本站提出的概念或组织框架，不是文献通用术语。
- 符号的含义与撞车提醒见[符号表](notation.md)。
